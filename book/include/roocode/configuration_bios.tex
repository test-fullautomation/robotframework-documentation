\section{Configuration}
\begin{boxhint}{Pre-condition}
Ensure the \textbf{GitHub Copilot} Extensions are installed and you are signed
in with your GitHub account.

Please refer to the chapter \hyperref[chap:copilot]{GitHub Copilot Extension}
for detailed installation and sign-in instructions.

\end{boxhint}

Steps to configure Roo Code Extension to use GitHub Copilot:
\begin{enumerate}
   \item Open \textbf{VSCodium For RobotFramework}.
   \item Click the \textbf{Roo Code icon} in the Activity Bar.
   \item Select \textbf{Use another provider} option at Welcome screen of extension (First time use).

         Or click the \textbf{Settings (gear icon)} at the top of the Roo Code panel (Already configured).
   \item In the \textbf{API Provider} option, select \textbf{VS Code LM API}
      as the provider.
   \item Choose the available model within the dropdown menu.
\begin{boxhint}{The list of models may change over time}
The list of LLM models may be changed dynamically based on the models supported
by Bosch GitHub Copilot at the moment.
\end{boxhint}
   \item Click \textbf{Done}.
\end{enumerate}

\section{Which LLM to Use}

As configured in previous chapters, Roo Code uses \textbf{Bosch GitHub Copilot}
as its AI backend.

Bosch GitHub Copilot provides access to a range of powerful LLMs, each with
different strengths and optimal use cases.

Simply pick the model that fits your task best — all models are covered by the
Bosch subscription, so just focus on choosing the right one for the job.

\subsection{Recommended Model Selection}

\begin{itemize}
   \item \textbf{Maximum Accuracy} (complex architecture, deep multi-file
      reasoning, autonomous debugging across large codebases):
      Use \textit{Claude Opus 4.6} — the highest-accuracy model available
      via Copilot. \textit{Claude Opus 4.5}
      is a close alternative.
   \item \textbf{High Accuracy + Speed} (demanding agentic tasks where response
      time matters):
      Use \textit{Claude Opus 4.6 (fast)} or \textit{GPT-5.3-Codex} —
      near-Opus accuracy at significantly faster response times.
   \item \textbf{Best Speed + Accuracy} (everyday agentic tasks, feature
      implementation, test generation, refactoring):
      Use \textit{GPT-5.2}, \textit{GPT-5.2-Codex}, \textit{GPT-5.1-Codex},
      or \textit{Claude Sonnet 4.6} — these deliver strong accuracy
      at fast response times.
   \item \textbf{Simple / Read-only Tasks} (asking questions, explaining code,
      quick lookups): \textit{GPT-4.1} or \textit{GPT-5 Mini} respond
      instantly and are sufficient for non-agentic interactions.
\end{itemize}

\begin{boxwarning}{Do not use mini or lightweight models for agentic tasks}
Models such as \rcode{GPT-5 Mini}, \rcode{GPT-4.1}, and
\rcode{Claude Haiku 4.5} are optimized for instant responses on simple
queries — \textbf{not} for the complex multi-step reasoning, multi-file
editing, and tool use that agentic development requires.
Use them only for simple, read-only interactions.
\end{boxwarning}

\begin{boxhint}{The model list changes over time}
GitHub Copilot regularly adds, updates, and retires models.
Always check the current list in the model dropdown within VS Code,
or refer to the official documentation:
\href{https://docs.github.com/en/copilot/using-github-copilot/ai-models/supported-ai-models-in-copilot}
{Supported AI models in GitHub Copilot}.
\end{boxhint}

\end{boxhint}
