\section{Configuration}
Before using Roo Code, you must configure an AI Language Model.
You can choose between AI Providers models, local models (via Ollama) or
GitHub Copilot.

Now, get started by selecting your preferred model provider as shown below:

\includegraphics{./include/graphics/roocode/RooCodeUseLLMProviders.png}

\subsection{API Provider Configuration}
\begin{boxhint}{Pre-condition}
You must obtain an API Key from a provider.
List of supported AI service providers:
\begin{itemize}
   \item OpenAI
   \item Google Gemini
   \item Anthropic
   \item \dots
\end{itemize}
\end{boxhint}

\begin{enumerate}
   \item Open \textbf{VSCodium For RobotFramework}.
   \item Click the \textbf{Roo Code icon} in the Activity Bar.
   \item Select \textbf{Use another provider} option at Welcome screen of extension (First time use).

         Or click the \textbf{Settings (gear icon)} at the top of the Roo Code panel (Already configured).
   \item Select your provider (e.g., \textbf{Anthropic} for Claude 3.5 Sonnet).
   \item Enter your \textbf{API Key}.
   \item Choose the specific model (e.g., \texttt{claude-3-5-sonnet-20241022}).
   \item Click \textbf{Done}.
\end{enumerate}

Refer to the image below for an example of using \textbf{Google Gemini} as
the API provider:

\includegraphics{./include/graphics/roocode/AIProviders.png}

\subsection{Local Model Setup (Ollama)}
For maximum privacy, you can run models locally.
\begin{boxhint}{System Requirement}
Running local models requires significant RAM/GPU resources.
\end{boxhint}

\begin{boxhint}{Pre-condition}
   You need to have Ollama installed and a local model downloaded.
   \begin{itemize}
      \item Download and install Ollama from
         \href{https://ollama.com/download}{Download Ollama}
      \item Use Ollama CLI to pull a coding model:
         \rcode{ollama pull deepseek-v3.1} or \rcode{ollama pull qwen3-coder}.
         You can find other models provided by Ollama at
         \href{https://ollama.com/library}{Ollama Library}.
      \item Ensure Ollama and pulled models are running locally on your machine.

            \includegraphics{./include/graphics/roocode/OllamaModels.png}
   \end{itemize}

\end{boxhint}

Steps to configure Roo Code with \textbf{Ollama}:
\begin{enumerate}
   \item Open \textbf{VSCodium For RobotFramework}.
   \item Click the \textbf{Roo Code icon} in the Activity Bar.
   \item Select \textbf{Use another provider} option at Welcome screen of extension (First time use).

         Or click the \textbf{Settings (gear icon)} at the top of the Roo Code panel (Already configured).
   \item In the \textbf{API Provider} option, select \textbf{Ollama}
      as the provider.
   \item Ensure the Base URL is set (usually \rcode{http://localhost:11434}).
   \item Choose the local model you pulled earlier.
   \item Click \textbf{Done}.
\end{enumerate}

\includegraphics{./include/graphics/roocode/OllamaProvider.png}

\section{Which LLM to Use}

Choosing the right LLM is \textbf{crucial} when working with Roo Code.
Agentic software development — where the AI autonomously edits multiple files,
executes terminal commands, reasons about test failures, and orchestrates complex
tasks — is one of the most demanding use cases for any language model.

\subsection{What Makes a Model Suitable for Agentic Development?}

When choosing a model for Roo Code, prioritize models that score well on the
following benchmarks:
\begin{itemize}
   \item \textbf{SWE-bench Verified:} Measures the ability to resolve
      real-world GitHub issues autonomously — the closest benchmark to what
      Roo Code does in practice.
   \item \textbf{LiveCodeBench:} Evaluates coding performance on recent,
      unseen problems, testing true generalization rather than memorization.
   \item \textbf{Tool Use / Function Calling:} Essential for Roo Code to
      reliably interact with your file system and terminal.
   \item \textbf{Long Context Handling:} Large codebases require a model that
      can maintain coherent reasoning over many thousands of tokens.
\end{itemize}

\textbf{Recommended Strategy:}
\begin{itemize}
   \item \textbf{Complex Agentic Tasks} (refactoring, architecture, debugging,
      multi-file generation): Use \textit{Claude 4.5 Opus}, \textit{Claude Opus 4.6},
      or \textit{GPT-5.2}.
   \item \textbf{Balanced Tasks} (feature implementation, test generation):
      \textit{Claude 4.5 Sonnet} offers the best cost-to-capability balance.
   \item \textbf{Private / Offline Tasks}: \textit{DeepSeek V3.2} via Ollama
      is the strongest local option.
\end{itemize}

\begin{boxwarning}{Mini models are not suitable for agentic tasks}
For reference, \rcode{GPT-5 Mini} scores only 56.2\% on SWE-bench Verified
(snapshot 2026-02-17, see table source above) — more than 20 percentage points
behind the top models.
Mini models are optimized for speed and cost, not for the complex multi-step
reasoning that agentic development requires.
\end{boxwarning}

\begin{boxhint}{The LLM landscape changes rapidly}
New models are released frequently and rankings shift — the best model today
may be superseded in just a few months.
Rather than relying on a fixed recommendation in this document,
ask an up-to-date AI assistant directly using the prompt below:

\medskip
\textit{"Which LLM models are particularly suitable for agentic software
development? Please provide a ranking."}
\end{boxhint}
